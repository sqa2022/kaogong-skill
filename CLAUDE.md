# Repository guidance

This repository is Chinese-first.

Current focus:
- Build a Claude Code skill for 公务员岗位推荐 / shortlist generation.
- Prioritize file-native workflows over generic chat behavior.

Editing rules:
1. Keep the scope narrow: position recommendation first.
2. Separate hard eligibility filtering from preference ranking.
3. Mark ambiguous cases as 待核验 instead of guessing.
4. Keep examples, templates, and skill instructions in sync.
5. Default output language is Simplified Chinese.

# 岗位推荐的硬性筛选规则

初筛时先把岗位分为三类：
- 明确可报
- 明确不可报
- 待人工核验

## 1. 学历与学位
- 岗位要求高于候选人学历或学位时，判为“明确不可报”。
- 字段缺失或表述模糊时，判为“待核验”。

## 2. 专业要求
- “专业不限”直接视为通过。
- 候选人专业被岗位要求精确命中时，可视为通过。
- 只写大类、相关专业、学科门类时，不默认通过，标为“待核验”。

## 3. 政治面貌
- “不限”视为通过。
- 明确要求“中共党员”而候选人不是时，判为“明确不可报”。

## 4. 应届身份
- 明确要求应届而候选人不是，判为“明确不可报”。
- 年份口径不清或地方定义特殊时，标为“待核验”。

## 5. 年龄
- 岗位写明年龄上限且候选人超出时，判为“明确不可报”。
- 备注里有年龄条件但难以解析时，标为“待核验”。

## 6. 基层经历
- 明确要求 N 年基层/工作经历而候选人不满足时，判为“明确不可报”。
- 经历类型口径不清时，标为“待核验”。

## 7. 户籍 / 生源地 / 服务基层项目
- 岗位明确限制本地户籍或生源地而候选人不匹配时，判为“明确不可报”。
- 地方性表述不清时，标为“待核验”。

## 8. 备注字段
备注优先级很高。若备注涉及体测、轮岗、执法、值班、长期出差、资格证书等条件，优先人工核验。

## 总原则
- 能明确排除的直接排除。
- 不能明确确认的不要默认放行。
- 高潜力但有边界风险的岗位可以保留在 shortlist 中，但必须把风险写清楚。

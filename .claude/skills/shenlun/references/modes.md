# Modes quick reference

## analyze

建议输出骨架：

1. 题型判断
2. 任务拆解
3. 材料主线
4. 主立意与备选立意
5. 文章结构
6. 可直接落笔的金句与段落起手式
7. 简提纲
8. 完整参考稿（仅在用户要求时提供）

## exemplar

建议输出骨架：

1. 检索到的近似主题
2. 为什么相近
3. 每篇样本可借鉴点
4. 范文正文
5. 不建议照搬之处

## grade

建议输出骨架：

1. 输入完整性检查
2. 总分与分项分
3. 总评
4. 核心失分点
5. 逐段点评
6. 局部改写示例
7. 整篇优化框架
8. 7 天提升计划

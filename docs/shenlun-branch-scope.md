# 申论分支范围说明

分支名：`feat/shenlun-core`

## 当前目标

只解决三件事：

1. 题目分析讲解并写作
2. 查找并给出参考范文
3. 批改打分用户提交的申论

## 当前命令设计

对外只保留一个显式入口：`/shenlun`。

通过 mode 参数区分：
- `analyze`
- `exemplar`
- `grade`

## 暂不纳入

- 行测题库与解析
- 招考公告抓取
- 职位匹配
- 实时网页检索依赖的复杂工作流
- 省份差异化的精细官方评分映射

## 设计取舍

### 为什么先用一个总入口？

因为更利于演示、传播和冷启动，也更便于在一个 skill 内统一维护审题、范文和批改的共享规则。

### 为什么先用内部练习分？

因为不同地区、不同年份的写作风格和评分口径有差异。第一版先把内部输出的一致性做出来，再逐步做 profile 化微调。
